# ExtensaoUFRRJ
Projeto de extensão criado por alunos da Universidade Federal Rural do Rio de Janeiro para compartilhamento de eventos na cidade de Seropédica. 

PRIMEIROS PASSOS
1. Criação e compartilhamento do repertório GitHub
2. Definição do método de organização -> Utilizar aplicativo para definir tarefas e fluxo de processos
3. Criar documento do projeto de extensão
4. Definir Design do projeto
5. Definir funcionalidades do projeto


# DESCRIÇÃO DO PROJETO
O projeto consiste no desenvolvimento de uma plataforma web de mapeamento colaborativo voltada ao município de Seropédica, com o objetivo de reunir e disponibilizar informações de interesse da comunidade em um mapa interativo.

A plataforma permitirá que usuários cadastrados contribuam com informações sobre diferentes pontos e atividades existentes no município, como eventos culturais, festas, atividades esportivas, estabelecimentos, projetos sociais, atividades acadêmicas, espaços de lazer, feiras, serviços e outros pontos de interesse da população.

Por meio de uma interface cartográfica interativa, os usuários poderão localizar um ponto no mapa, inserir informações sobre ele, selecionar sua categoria, adicionar descrição, data, horário, imagens e outras informações relevantes. Essas contribuições poderão ser consultadas pelos demais usuários, criando um mapa colaborativo e dinâmico de Seropédica.

Além da disponibilização de informações, o projeto busca aproximar a Universidade Federal Rural do Rio de Janeiro da comunidade local, utilizando a Cartografia e as Tecnologias da Informação como ferramentas de extensão universitária, participação social e democratização do acesso à informação espacial.

Dessa forma, a plataforma funcionará como um espaço digital de construção coletiva do conhecimento sobre o território, permitindo que informações produzidas e compartilhadas pela própria comunidade sejam organizadas espacialmente e disponibilizadas de maneira acessível.
